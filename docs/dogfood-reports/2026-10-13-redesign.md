# goDiesel redesign and browser verification — October 13, 2026

## Result

Implemented the approved editorial-atlas direction across Atlas, Finder, Routes, route guides, Replay, and the Admin workspace. The shared language is warm paper, forest actions, serif headings, restrained secondary text, rounded panels, and shared buttons/inputs with a minimum 44-pixel touch height. Actual route geometry, recorded metrics, source labels, and draft/reviewed status remain visible.

## Changes

- **Navigation and foundations:** consistent Atlas/Finder names; a quieter sidebar; one library title rather than duplicate headers; common surface radii and stronger muted-text contrast. Dialog controls inherit usable touch sizes without depending on page-level theme ancestry.
- **Routes:** replaced the dense ledger with responsive preview cards using real route traces. Cards distinguish completed, discovered, and planned routes, and separate draft from reviewed guidance. Search stays visible; optional filters expand together. URL filters and return position remain intact.
- **Finder:** persistent place search, optional advanced filters, quick starting places, clear empty/no-match states, and simpler candidate cards. Finder still searches recorded/curated routes; it does not imply generated routes.
- **Guides:** map and editorial margin work together on desktop and tablet. The mobile sheet has bounded peek/half/expanded states, scrollable detail, and a fixed Replay action. Atlas-origin guides retain the selected region/route when returning or entering Replay.
- **Atlas:** consistent controls and route cards with separate Route guide and Open replay actions. Fixed a reproduced browser-Back race where an already-loaded fallback map failed to reassert presentation readiness, leaving the carousel in a loading state.
- **Replay:** reorganized the control dock so distance, elapsed time, pace, elevation, and grade fit without overlap. Camera controls remain directly available on wider screens and move into settings on phones. Fixed the live Replay layer covering the route-picker dialog; regression checks inspect the actual hit target.
- **Admin:** aligned typography and surfaces with the rest of the app while preserving the bounded editor, sticky actions, validation, and writer connection state.

## Scope and limitations

This is a local, uncommitted implementation. No production deployment or GitHub merge was performed. Existing migration and dependency-remediation work in the checkout was preserved. Live Admin persistence was not exercised because the local owner writer is disconnected; its validation/save paths are covered by automated fixtures. The automated release suite intentionally skips opt-in provider/lab/microsite scenarios; relevant live Atlas checks are reported separately.
