# Sovereign Adventure Worlds unresolved questions

These questions are recorded because current repository evidence cannot answer them truthfully.
They do not block the deterministic compiler foundation unless marked as a stage gate.

| Question | Why unresolved | Gate |
| --- | --- | --- |
| Which licences permit retained terrain, orthophoto, vector, building, LiDAR, and reconstruction assets for each reference corridor? | Current runtime providers do not grant an implied right to archive their visual tiles. | Blocks each source adapter and sealed pack that uses it. |
| Where are original owner GPX or FIT files and owner media retained for the three reference routes? | Public route details expose normalized data but private originals must not enter this repository. | Blocks Archival pack completeness and private source repair proof. |
| What open terrain source and resolution meet the owner-Mac Core performance and visual thresholds for Japan and Canada? | No focused source and format spike has been completed. | Blocks Detailed terrain acquisition, not procedural Core compiler tests. |
| What structure and transportation sources provide adequate coverage for Tokyo, Banff, and Ucluelet? | Current visual providers are live and not archival sources. | Blocks world-fidelity and navigation quality gates. |
| What fixed-timestep locomotion model and avatar dimensions are canonical for walking, running, and riding? | Playable Earth has camera movement but no physical actor contract. | Blocks Stage 5. |
| What numerical grounding-error, slope, step, stair, bridge, tunnel, and collision tolerances apply by mode? | The goal names failure categories but only grounding has a numeric human-quality target. | Blocks Stage 5 acceptance. |
| What route-corridor width and free-roam exploration boundary are appropriate per world? | Source density, terrain, and intended exploration differ materially. | Must be fixed in each pack build configuration before Stage 3. |
| What perceptual image threshold is acceptable for deterministic GPU renders? | Current film tests verify frame identity under one runtime but do not define cross-GPU equivalence. | Blocks cross-machine cinematic acceptance. |
| What archive licence and privacy policy allows a clean-machine proof without exposing owner-private evidence? | The repo is public and the full World Pack may contain restricted owner media or source traces. | Blocks sharing Archival archives; local clean-room proof can proceed. |
| Who supplies the blind critic ratings and final human-quality approval? | An agent cannot substitute for the owner's or a fresh human critic's subjective experience. | Blocks final promotion and goal completion. |

## Domain-modeling gaps

The goal introduces World Pack, quality cell, visual world, physical world, acquisition adapter, transformation graph, sealed version, repair, and pack health.
These terms need an accepted ADR and `CONTEXT.md` update after the contract spike proves their boundaries.
Until then, implementation uses them only inside the isolated World Pack module and its documentation.
