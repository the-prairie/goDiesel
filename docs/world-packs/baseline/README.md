## Provider-disabled current runtime

`current-runtime-provider-disabled.json` is generated by the read-only Playwright baseline harness.
The harness builds the current application with Google providers disabled, aborts every non-local HTTP request, and exercises Playable Earth, default Replay, and Atlas Replay for Tokyo, Banff/Kananaskis, and Ucluelet.

Capture command on 2026-08-26:

```sh
GODIESEL_CAPTURE_WORLD_PACK_BASELINE=1 \
  npx playwright test --config playwright.world-pack-baseline.config.ts
```

Result: 1 passed in 58.1 seconds, with the measured journey itself completing in 50.4 seconds.

The result proves:

- every strict route detail loaded locally;
- Playable Earth was unavailable without a Google Map Tiles key;
- default Replay was unavailable without a Google Maps JavaScript key;
- Atlas Replay attempted `https://tiles.openfreemap.org/styles/fiord` and became unavailable when that non-local request was blocked;
- none of the current immersive paths met the World Pack offline contract.

The output records attempted request origin and path but no credentials, query strings, private source values, or response bodies.
